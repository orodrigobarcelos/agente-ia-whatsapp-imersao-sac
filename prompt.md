# Prompt do meu agente

> **Esse arquivo é um espelho local do `system_prompt` que está no banco de dados (`agent_configs.system_prompt`).**
>
> A fonte da verdade é o **DB** — quando o agente roda, ele lê do Postgres, não desse arquivo. Aqui é só pra você ter um histórico visível e legível das edições.
>
> Pra editar de verdade, peça ao Claude Code: *"deixa o agente mais X"*, *"adiciona regra Y"*, *"muda tom de voz"* — ele atualiza o DB e atualiza esse arquivo aqui também.
